## 🚀 Featured Project — AI Support Operations Agent

My main production project is an **AI agent for technical support operations**.

It started as a personal assistant for categorizing support requests. Then colleagues asked for access.

Today it is used by **5 team members** and monitors approximately **100 customer chats**.

The agent can:

- 🧠 **Detect and classify real technical issues** while ignoring everyday conversation and noise
- 📋 **Create structured support cases** with customer context, cluster, issue title, description, and related metadata
- 🔎 **Search the knowledge base** and decide whether a problem is simple or requires escalation
- 🎫 **Orchestrate Jira & YouTrack workflows** — draft tickets, create them after explicit human approval, assign responsible teams, and track updates
- 👁️ **Understand visual context** with Vision AI for screenshots and other visual evidence
- 🚨 **Detect emerging incidents** by correlating semantically similar reports from multiple customers within a time window
- 🛠️ **Use operational tools** for controlled actions inside internal systems
- 📊 **Query operational data** through logs and read-only analytical queries

The system doesn't just generate text.

**It observes → reasons → retrieves context → uses tools → tracks state → escalates → reports back.**

High-impact actions remain behind **human-in-the-loop approval**.

`Production` · `~100 monitored chats` · `5 users` · `AI Agents` · `Vision AI` · `Jira` · `YouTrack` · `RAG` · `Tool Calling`
