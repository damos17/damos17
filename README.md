## 🚀 Featured Project — AI Support Operations Agent

My main production project is an **AI agent for technical support operations**.

It started as a personal assistant for categorizing support requests. Colleagues then asked for access. Today it is used by **5 team members** and monitors approximately **100 customer chats**.

The system can:

- 🧠 detect and classify real technical issues while ignoring everyday conversation and noise;
- 📋 create structured support cases with customer context and issue metadata;
- 🔎 search a knowledge base and decide whether a problem is simple or requires escalation;
- 🎫 orchestrate Jira and YouTrack workflows, with ticket creation behind explicit human approval;
- 👁️ understand screenshots and other visual evidence with Vision AI;
- 🚨 correlate similar reports from multiple customers into emerging incidents;
- 🛠️ use bounded operational tools inside internal systems;
- 📊 query logs and read-only analytical data for diagnostics.

**It observes → reasons → retrieves context → uses tools → tracks state → escalates → reports back.**

High-impact actions remain behind **human-in-the-loop approval**.

`Production` · `~100 monitored chats` · `5 users` · `AI Agents` · `Vision AI` · `Jira` · `YouTrack` · `RAG` · `Tool Calling`
